# Disparo pela extensão do Claude no Chrome

Como usar: abra o Chrome com a extensão ativa, deixe o **WhatsApp Web logado**
em uma aba, abra o claude.ai em outra, **anexe o arquivo
`mensagens_5b-atraso.txt`** e cole o prompt abaixo.

---

## Prompt para colar

Tenho o WhatsApp Web aberto e logado nesta janela do Chrome. No arquivo anexado
há 63 mensagens, cada uma com um cabeçalho `===== Nome · +telefone =====`
seguido do texto a enviar.

Para cada contato, um de cada vez, na ordem do arquivo:
1. abra `https://wa.me/<telefone sem o +>` na aba do WhatsApp Web;
2. confira que a conversa aberta é a do telefone certo;
3. cole o texto correspondente **exatamente como está**, sem reescrever nada,
   preservando os asteriscos de negrito, as quebras de linha e os emojis
   (🧡 💙 🦕);
4. envie e me diga "enviado: <nome>" antes de passar para o próximo.

Regras: não invente nem resuma texto; não envie para número que não esteja no
arquivo; se uma conversa não abrir ou o número parecer inválido, pule e me
avise. Pare e me pergunte se qualquer coisa fugir do esperado.
