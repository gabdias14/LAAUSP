Área do representante

Acesso restrito aos representantes das atléticas escalados para a mesa.

Esta é uma versão piloto: a senha fica no código do site e serve só para esconder a tela do operador durante os testes. Não guarde dados sensíveis aqui até existir autenticação no servidor.

Conferência de e-Card

Aponte a câmera para o QR Code do e-Card USP do atleta, ou envie a foto do e-Card. A conferência é feita contra a lista de inscritos da modalidade.

Aguardando leitura

Ligue a câmera e centralize o QR Code do e-Card na mira.
